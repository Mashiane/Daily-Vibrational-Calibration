## Deployment to Vercel

1. Push your project containing index.html and README.md to a GitHub repository.
2. In Vercel, select Add New Project and import the repository.
3. Leave Framework Preset as Other and build/output settings blank.
4. Click Deploy.

## Mobile and PWA Usage

The app is responsive across mobile viewports. To install on Android or iOS:
- Open your deployed URL in Chrome or Safari.
- Select Add to Home Screen from the browser menu.
- Launch in full-screen standalone mode.
